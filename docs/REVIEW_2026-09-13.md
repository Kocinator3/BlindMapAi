## Confirmed interaction defects corrected

1. Scale end unconditionally closed touch river strokes. They remained acceptable LineStrings, so the old submit test missed the return segment. Only area strokes now close.
2. Touch pointer-count changes restart the scale recognizer. Drafts were emitted during pinch and after lifting one finger. A pointer-lifetime navigation latch cancels drafts before ownership changes.
3. Polygon drag followed the placement/pan policy instead of the requested area policy. Polygon supports trace-to-area and vertex-click authoring.
4. Type updates left selected tool and scale state alive. Central cancellation and complete reset fix this; same-type gameplay questions get fresh keyed map instances.
5. Shared mouse-click suppression could affect subsequent non-mouse taps. Tap dispatch now uses event device kind.
6. Area edit tools were classified as freehand solely from answer type, preventing desktop delete/add clicks. Ownership now checks selected tool. Ring editing omits the closing duplicate handle.
7. Escape/right-click left Point gameplay in an invisible Navigate mode with no Draw control. They now cancel back to Draw; temporary pan remains available.
8. Native image inspection revealed a lost first corner: scale recognition began after pointer-down. Drawing/moving now uses the original pointer-down position, including circle centers. Rectangle regressions check all four corners and the starting longitude.

The mountain pack already contains freehandArea and circle questions with Polygon references. No ID/title/index workaround or data retyping was needed. Approximations remain unverified. Canonical validation precedes scoring; crossing or degenerate attempts produce validation errors.
